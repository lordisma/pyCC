# Contributing to Clustlib

🎉 First off, thank you for your interest in contributing! We’re excited to build this project together, and we appreciate the time and energy you’re putting in.

## Code of conduct

Please refer to our [Code of conduct](CODE_OF_CONDUCT.md) to know some base rule of the community

## 📋 How to Contribute
We welcome contributions of all kinds—whether it’s fixing bugs, adding new features, improving documentation, or sharing ideas. Here’s how to get started:

1. **Fork & Clone the Repo**
   - Fork this repository to your GitHub account.
   - Clone your fork locally:
     ```bash
     git clone git@github.com:lordisma/pyCC.git
     cd pyCC
     ```

2. **Create a Branch**
   - Make a new branch for your work:
     ```bash
     git checkout -b feature/your-feature-name
     ```

3. **Make Your Changes**
   - Keep commits clear and focused.
   - Follow the coding style and guidelines below.
   - Make sure pre-commits rules are successfull

4. **Test Your Changes**
   - Ensure everything runs smoothly and doesn’t break existing functionality.

5. **Submit a Pull Request (PR)**
   - Push your branch to your fork.
   - Open a PR against the `main` branch of this repository.
   - Fill in the PR template with details about your changes.
   - PR will need an approbal from mantainers

---

## 🛠 Code Guidelines
- Follow consistent naming conventions and [format](https://black.readthedocs.io/en/stable/the_black_code_style/current_style.html).
- Write meaningful [commit messages](https://www.conventionalcommits.org/en/v1.0.0/).
- Add [comments](https://gist.github.com/redlotus/3bc387c2591e3e908c9b63b97b11d24e) where necessary for clarity.
- If applicable, include or update tests when adding new features or fixing bugs.

---

## ✅ Pull Request Checklist
Before submitting, please confirm:
- [ ] The code builds and runs without errors.
- [ ] Linting/formatting rules are followed.
- [ ] Tests are passing.
- [ ] Documentation is updated where needed.

---

## 💬 Communication
- Use GitHub Issues for bug reports and feature requests.
- Be respectful and constructive in all discussions.
- Follow our [Code of Conduct](CODE_OF_CONDUCT.md).

---

## 🚀 Getting Help
If you’re unsure about anything, don’t hesitate to ask questions by opening an issue or starting a discussion. We’d rather have you ask than feel stuck!
